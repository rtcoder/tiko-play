# TikoPlay 0.7

Wydanie porządkuje wersjonowanie aplikacji i automatyzuje dostarczanie instalatorów.

## Zmiany

- Push tagu uruchamia testy oraz budowanie paczek macOS (Apple Silicon i Intel) i instalatora Windows x64. GitHub Release powstaje dopiero po powodzeniu wszystkich zadań; zawiera też sumy SHA-256.
- Numer w nagłówku panelu (`.version`) i Ustawieniach pochodzi ze wspólnego pliku `VERSION`. Znikają mylące, stałe oznaczenia 2.0/2.0.0; metadane macOS i instalator Windows używają tej samej wersji co tag.
- Każde wydanie wymaga opisu zmian w repozytorium. Niezgodny tag lub brak opisu przerywa workflow przed budowaniem.

## Numer wydania

Przejście z v0.4 do v0.7 obejmuje trzy odrębne obszary: automatyzację publikacji, wspólne źródło wersji oraz zasady i opisy wydań. Numery nie są licznikiem commitów ani zadań.

## Instalacja i ograniczenia

- macOS: wybierz DMG `arm64` dla Apple Silicon albo `x86_64` dla Intela, następnie przeciągnij aplikację do Applications.
- Windows x64: uruchom plik `-setup.exe`.
- Paczki nie mają podpisu dystrybucyjnego ani notaryzacji Apple; system może wymagać ręcznego zatwierdzenia uruchomienia. Istniejąca konfiguracja użytkownika pozostaje na miejscu.
- Testy automatyczne korzystają z atrap integracji. Nie potwierdzają działania rzeczywistego czatu LIVE ani wysyłania klawiszy w konkretnej grze. Twitch nadal wymaga skonfigurowanego Client ID.

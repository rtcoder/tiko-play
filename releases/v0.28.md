# TikoPlay 0.28 — instalator Windows

## Zmiany dla użytkownika

- Kreator instalacji po polsku i angielsku, z instrukcją aktualizacji i zachowania danych.
- Skrót na pulpicie jest opcjonalny, domyślnie wyłączony; aplikacja pozostaje dostępna w menu Start. Instalator pamięta wybór przy kolejnej instalacji. Odznaczenie nie usuwa wcześniejszego skrótu.
- Uruchomienie aplikacji na końcu instalacji wymaga zaznaczenia opcji.
- Instalacja na bieżącym koncie bez podnoszenia uprawnień; instalator odrzuca systemy bez obsługi aplikacji x64.
- Aktualizacja zachowuje dotychczasowy katalog i identyfikator instalacji. Dane profili, preferencje, ustawienia OBS i kopie konfiguracji pozostają również po odinstalowaniu.

## Weryfikacja dystrybucji

Workflow wykonuje test gotowego instalatora Windows: świeża instalacja PL bez skrótu, aktualizacja z poprzedniego opublikowanego wydania w katalogu ze spacjami, EN ze skrótem, reinstalacja, start zainstalowanego EXE i lokalnego panelu oraz deinstalacja. Sumy plików-fixtur sprawdzają zachowanie danych. Ręczne uruchomienie workflow pozwala sprawdzić paczki przed publikacją. Błąd testu blokuje wydanie.

Potwierdzono w [kontrolnym workflow](https://github.com/rtcoder/tiko-play/actions/runs/37199517075): test instalacji i aktualizacji v0.27 → 0.28 zakończony sukcesem, trzy gotowe paczki, 274 testy Python (1 pominięty) i 53 frontend na każdej platformie. Lokalna paczka macOS arm64 przeszła kontrolę podpisu ad-hoc i integralności DMG.

## Numer wersji

0.27 → 0.28: jeden spójny zakres dotyczący instalacji i jej weryfikacji. Bez przebudowy aplikacji, zmian schematu konfiguracji ani nowych integracji; dlatego niewielki skok minor i bez zmiany major.

## Ograniczenia i instalacja

Przed aktualizacją zatrzymaj nasłuch i wybierz „Zakończ TikoPlay” z traya; zamknięcie karty przeglądarki nie wystarcza. Instalator korzysta z Restart Managera bez wymuszonego zamykania i bez automatycznego restartu aplikacji. Nie usuwa starych nieużywanych bibliotek ani własnych plików w katalogu instalacji.

Odinstalowanie zachowuje `%APPDATA%\TikoPlay` oraz poświadczenia w Windows Credential Manager. W celu usunięcia poświadczeń odłącz konta/usuń klucze w aplikacji przed deinstalacją.

Test CI działa na Windows Server 2022 z narzędziami developerskimi; nie zastępuje ręcznego odbioru kreatora na czystym Windows 10/11, konta bez uprawnień administratora, traya, zamykania podczas LIVE i rzeczywistej gry. Test startu używa izolowanych danych i nie łączy się z czatem ani nie wysyła klawiszy. Paczki nadal nie mają podpisu dystrybucyjnego Authenticode/Developer ID ani notaryzacji macOS.
